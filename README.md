# موقعي الشخصي

هذا موقعي الذي أعرض فيه أعمالي في نظم المعلومات الجغرافية وتطوير أنظمة الويب.

**الموقع:** https://mmashharawi2021-cell.github.io/

## لماذا بنيته

السيرة الذاتية وحدها لا تُظهر الشغل الحقيقي. لما أكتب "دققت بيانات أكثر من 20 ألف وحدة سكنية" أو "بنيت نظام لإدارة الكفالات"، القارئ ما بيشوف شي. فقررت أعمل مكان واحد يجمع أعمالي وصورها وسيرتي، وأقدر أرسل رابطه لأي جهة بدل ملفات متفرقة.

## ماذا ستجد فيه

- أعمالي في GIS والحصر الميداني، ومنها UN Field ولوحة الحصر الميداني.
- الأنظمة التي طوّرتها، مثل منصة رِفق ونظام تشغيل المياه.
- سيرتي الذاتية كصفحة مستقلة بالعربية والإنجليزية، مع ملف PDF.
- طريقة للتواصل معي مباشرة عبر واتساب.

## كيف بنيته

React و TypeScript و Vite، والموقع ثابت بالكامل بلا خادم، ويُنشر تلقائياً على GitHub Pages عند كل تحديث.

أكثر شي تعبني هو العربي. أغلب التأثيرات الجاهزة مصممة للإنجليزي: بتقسم الكلام حرف حرف فتنفصل الحروف العربية عن بعض، أو بتمشي من اليسار لليمين عكس القراءة. فاضطريت أعدّل كل تأثير ليشتغل بالكلمة بدل الحرف وباتجاه اليمين. وجربت تأثيرات كثيرة على البطاقات والعناوين وشلت أغلبها، لأني بفضّل الموقع يكون واضح أكثر من إنه يكون مليان حركة.

## تشغيله على جهازك

```sh
npm ci
npm run dev
```

ثم افتح http://localhost:5173/

## ما زلت أعمل عليه

- تحسين سرعة فتح الموقع على الجوال.
- إضافة دراسات حالة لباقي المشاريع، مثل اللي موجودة حالياً لـ UN Field ولوحة الحصر الميداني.
